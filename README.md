# AD-07-LAB-El-sitio-del-blog
AD-07: LAB: El sitio del blog - Blog de 3 páginas con HTML y CSS (9/10/2026)
Laura Elvia Robellada López

Blog de 3 páginas sobre yoga ("Shanti Yoga"), hecho con HTML y CSS.

## Páginas
- Inicio (`index.html`)
- Quiénes somos (`about.html`)
- Contacto (`contact.html`)

## Tecnologías
- HTML5
- CSS3 (un solo archivo: `style.css`)

## Cómo verlo
1. Clona el repositorio.
2. Abre `index.html` en tu navegador, o usa la extensión Live Server de VS Code.

## Estructura
- `index.html`, `about.html`, `contact.html`: las páginas del sitio.
- `style.css`: estilos compartidos por las 3 páginas.
- `Pic/`: imágenes.
- `docs/`: instrucciones del laboratorio.

## Metodología
Se trabajó con SCRUM en un sprint de 1 semana. El tablero está en el
proyecto "Sprint 1 - Blog" de este repositorio.
